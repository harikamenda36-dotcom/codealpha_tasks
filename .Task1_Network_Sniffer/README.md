# CodeAlpha - Phishing Awareness Training

## Task
Phishing Awareness Training

## Objective
To educate users about phishing attacks, fake websites,
social engineering techniques, and safe online practices.

## Topics Covered
- What is phishing?
- How phishing attacks work
- Recognizing phishing emails
- Identifying fake websites
- Social engineering techniques
- Real-world phishing scenario
- Phishing prevention and safety practices
- Interactive quiz

## Tools Used
- Microsoft PowerPoint

## Project Outcome
This training module helps users identify common phishing
attempts and follow safer practices when handling suspicious
messages, links, and requests.
